# Yuwen Su

**Creative technologist · Human–AI interaction · Toronto**

I’m interested in what happens when making something with a computer feels more like a conversation. My starting points are visual art, digital products, and playful interaction. I’m drawn to interfaces where a small design choice, such as when a system responds or how it signals uncertainty, changes what someone feels able to do.

## Questions I’m exploring

- **Human–AI interaction.** When should a creative assistant suggest a direction, and when should it leave room for the person to explore?
- **Human–computer interaction.** How can an interface make unfamiliar inputs feel learnable and help people recover when the system misreads them?
- **Computational creativity.** How might interactive tools help people discover ideas they would otherwise miss while keeping creative decisions in their hands?
